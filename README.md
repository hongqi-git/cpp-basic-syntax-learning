# C++ 基础语法学习

一个可本地打开的单页 C++ 入门学习网页，包含按章节组织的讲解、代码编辑区和离线教学解释器。

## 使用方式

- 本地使用：下载仓库后，直接打开 index.html。
- 学习进度与代码草稿保存在当前浏览器的本地存储中。
- 示例运行区是轻量离线解释器，用于演示页面覆盖的基础语法，不是完整 C++ 编译器。
- 页面背景图片已内嵌在 HTML 中，无需额外资源文件。

## GitHub Pages

将仓库推送到 GitHub 后，可在仓库的 Settings → Pages 中选择从 main 分支的根目录发布。发布完成后，GitHub 会提供网页访问地址。
